### 🚀 Featured Project

#### 🛡️ [Customer Retention & Decision Support System](https://github.com/Tehreem-Waseem/customer-retention-system)

An end-to-end Machine Learning ecosystem predicting customer churn and converting probabilities into financial decisions and automated business interventions.

* **Key Capabilities:**
  * 🔄 **Architecture:** Built leakage-free Scikit-learn pipelines with cross-validation and hyperparameter tuning.
  * 🚦 **Decision Engine:** Stratifies churn risk into RED / ORANGE / GREEN zones with automated retention playbooks.
  * 💰 **Business Impact:** Includes ROI simulations to balance retention costs against churn recovery value.
  * ⚙️ **Production Quality:** Fully tested via PyTest, automated using GitHub Actions CI, and deployed on Streamlit.

**Stack:** Python • Pandas • NumPy • Scikit-learn • Streamlit • PyTest • GitHub Actions  
🔗 **[Repository](https://github.com/Tehreem-Waseem/customer-retention-system)** | 🚀 **[Live App](https://customer-retention-system-8zyvt6uptwnh9cfrdmeagw.streamlit.app/)**
